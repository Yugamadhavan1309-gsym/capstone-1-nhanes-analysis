# Capstone Project 1
## Analysis of NHANES Body Measurements Using NumPy Matrices

### Project Overview

This project analyses adult male and female body-measurement data from the National Health and Nutrition Examination Survey (NHANES) using Python and NumPy matrices.

The analysis focuses on body weight, height, BMI, waist circumference, hip circumference, and derived body-measurement ratios.

### Objectives

- Analyse male and female weight distributions
- Calculate descriptive statistical measures
- Calculate Body Mass Index (BMI)
- Standardise body measurements using z-scores
- Analyse relationships between body measurements
- Calculate Pearson and Spearman correlation coefficients
- Calculate waist-to-height and waist-to-hip ratios
- Compare body-measurement distributions
- Analyse participants with the lowest and highest BMI values

### Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Google Colab
- Jupyter Notebook

### Dataset

The project uses the NHANES adult male and female body-measurement datasets specified in the project instructions.

The datasets contain measurements including:

- Weight
- Standing Height
- Upper Arm Length
- Upper Leg Length
- Arm Circumference
- Hip Circumference
- Waist Circumference

### Analysis Performed

The notebook includes:

1. Loading and analysing the NHANES datasets
2. Weight distribution histograms
3. Male and female weight comparison using boxplots
4. Descriptive statistics and distribution analysis
5. BMI calculation
6. Z-score standardisation
7. Scatterplot matrix analysis
8. Pearson and Spearman correlations
9. Waist-to-height ratio calculation
10. Waist-to-hip ratio calculation
11. Comparison of body-measurement ratios
12. Analysis of the five lowest and five highest BMI participants
